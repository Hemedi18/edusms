EduSMS — Server Startup, cPanel (edusms.edusphere.co.tz) & GitHub Sync Commands

Click any Copy Command button below to copy the exact commands to your clipboard.

1. Start PostgreSQL, Redis & Django ASGI Server

Starts local databases, runs migrations, and boots Daphne on port 8000.

bash scripts/dev_services.sh start
backend/.venv/bin/python backend/manage.py migrate
backend/.venv/bin/daphne -b 0.0.0.0 -p 8000 --chdir backend edusms.asgi:application

2. Start React Web Dashboard

Launches the Vite web frontend on http://localhost:5173.

npm --prefix web run dev

3. Initialize & Push to GitHub (Hemedi18/edusms)

Initializes git on branch main and pushes to https://github.com/Hemedi18/edusms.git.

echo "# edusms" >> README.md
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/Hemedi18/edusms.git
git push -u origin main

4. Sync Latest Code from GitHub to Server

Pulls latest changes from origin/main, runs migrations, and rebuilds web assets.

git fetch origin main
git pull --ff-only origin main
backend/.venv/bin/python backend/manage.py migrate --noinput
npm --prefix web run build

5. Deploy on cPanel (edusms.edusphere.co.tz)

Deploys EduSMS inside public_html/edusms and restarts Phusion Passenger.

mkdir -p ~/public_html/edusms
cd ~/public_html/edusms
git clone https://github.com/Hemedi18/edusms.git . || git pull origin main
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt
backend/.venv/bin/python backend/manage.py migrate --noinput
backend/.venv/bin/python backend/manage.py collectstatic --noinput
mkdir -p tmp && touch tmp/restart.txt

6. Start Full Stack with Docker Compose

Starts PostgreSQL, Redis, Django ASGI, Celery Worker/Beat, and Web Dashboard.

cp .env.example .env
docker compose up --build -d
docker compose exec backend python manage.py migrate
